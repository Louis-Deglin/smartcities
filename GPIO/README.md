# Module GPIO : LED et Bouton-Poussoir

Ce répertoire contient mes codes Python avec d'abord les exercices pour s'entrainer et ensuite le code de l'exercice 1.

## Exercice demandé : Clignotement variable au clic

**Comportement programmé :**
* **1 clic :** Clignotement lent (0.5 Hz)
* **2 clics :** Clignotement rapide
* **3 clics :** Extinction de la LED (réinitialisation)
